# Security Policy

## Reporting a vulnerability
Please **do not** open a public issue for security problems.

Report privately via GitHub Security Advisories ("Report a vulnerability" on the Security tab)
or to `<security-contact@example.com>` (placeholder: replace before going public).

Include: affected component and version/commit, reproduction steps, impact, and any proof of concept.

## Our commitment
- Acknowledge receipt within 3 working days.
- Provide an initial assessment within 10 working days.
- Keep you informed until a fix is released, and credit you if you wish.

## Supported versions
Only the latest release on `main` receives security fixes.
